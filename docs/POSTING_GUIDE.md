# ✍️ 블로그 포스팅 및 디자인/기능 사용 완벽 가이드

이 문서는 블로그 포스팅을 작성할 때 발생하는 오류를 방지하고, 프로젝트 및 기술 블로그의 다양한 시각적 기능(캐러셀 슬라이드, 여러 줄 설명, 폰트 커스텀 등)을 100% 활용하기 위한 공식 사용 설명서입니다.

---

## 1. 포스팅 카테고리별 디렉토리 및 스키마 구조

블로그 포스팅은 목적에 따라 `src/content/` 하위의 3개 디렉토리(`notes`, `projects`, `stories`)로 나뉘어 관리됩니다. 파일 상단의 **YAML Frontmatter (`---` 사이 영역)** 작성 기준만 정확히 지키면 빌드 오류가 절대 발생하지 않습니다!

### 📌 1) Notes (기술 블로그 및 팁)
- **위치**: `src/content/notes/{파일명}.md`
- **주요 속성**:
  ```yaml
  ---
  title: "FastAPI와 Uvicorn의 관계, ASGI 정리"
  category: "Tech"                # 기본값 'Tech', 자유롭게 지정 가능
  subcategory: "Backend"          # 선택 사항 (없으면 null 또는 생략)
  tags: ["Python", "Backend"]     # 선택 사항 (배열 형태)
  date: 2026-06-16                # 필수 (YYYY-MM-DD)
  thumbnail: "../../assets/images/notes/my-post/thumb.png"  # 선택 사항
  ---
  ```

### 🚀 2) Projects (프로젝트 포트폴리오)
- **위치**: `src/content/projects/{파일명}.md`
- **주요 속성**:
  ```yaml
  ---
  title: "F1 통합 통계 인터랙티브 대시보드"
  period: "2024.03 - 2024.06"
  description: |
    1950~2026년 F1 전 시즌 통계를 통합한 인터랙티브 웹 대시보드.
    Streamlit과 MySQL 기반으로 드라이버·팀·레이스 데이터를 시각화하며, DB 설계와 드라이버 순위 페이지를 단독 담당.
  techStack: ["Python", "Streamlit", "MySQL", "Pandas"]
  githubUrl: "https://github.com/example/f1-dashboard"  # 선택 사항
  thumbnail: "../../assets/images/projects/f1-dashboard/thumb.jpg" # 선택 사항
  status: "Completed"             # 'Live', 'Completed' 또는 커스텀 상태어
  ---
  ```

### ☕ 3) Stories (일상, 회고 및 개발 스토리)
- **위치**: `src/content/stories/{파일명}.md`
- **주요 속성**:
  ```yaml
  ---
  title: "2025년 상반기 개발자 회고"
  date: 2025-06-30
  category: "회고"
  description: "올해 진행했던 주요 프로젝트와 성장 스토리를 나눕니다."
  tags: ["일상", "회고"]
  thumbnail: "../../assets/images/stories/story-1/thumb.png" # 선택 사항
  ---
  ```

## 2. 여러 줄 Description (줄바꿈) 작성 규칙

YAML에서 줄바꿈이 포함된 긴 글(예: 프로젝트 개요 등)을 적을 때는 한 줄로 욱여넣을 필요가 없습니다. **파이프(`|`) 기호**와 **들여쓰기(2칸)** 규칙만 기억하세요!

### ✅ 올바른 줄바꿈 문법 (`|` 사용법)
`description: |`를 적은 후 **반드시 엔터로 줄을 바꾼 뒤, 다음 줄부터 스페이스바 2칸을 들여써서** 작성합니다. (우리 블로그 시스템에 `whitespace-pre-line`이 적용되어 작성한 줄바꿈이 웹 화면에 그대로 예쁘게 출력됩니다!)

```yaml
description: |
  1950~2026년 F1 전 시즌 통계를 통합한 인터랙티브 웹 대시보드.
  Streamlit과 MySQL 기반으로 드라이버·팀·레이스 데이터를 시각화하며, DB 설계와 드라이버 순위 페이지를 단독 담당.
  
  (이렇게 여러 줄을 띄어 쓰고 구문과 구문을 구분해도 화면에 완벽하게 표시됩니다.)
```

## 3. 마크다운 본문(Prose) 스타일 & 글자 키우는 법

Tailwind CSS v4 환경에서도 본문 가독성이 최우선이 되도록 `global.css`의 `.prose` 영역에 고급 스펙이 설정되어 있습니다.

### 📝 제목(Heading) 크기 및 하단 경계선
마크다운 문서 본문에서 `#`, `##`, `###`을 사용해 자연스럽게 글자 크기를 키우고 구분할 수 있습니다.
- `# 대제목 (H1)`: **글자 크기 28px**, 가장 진하고 하단에 **굵은 실선 경계선**이 자동 부착됩니다.
- `## 중제목 (H2)`: **글자 크기 23px**, 진한 글씨에 하단 **얇은 실선 경계선**이 부착되며 목차(TOC) 상위에 출력됩니다.
- `### 소제목 (H3)`: **글자 크기 19px**, 하위 단락 구분에 적합하며 목차(TOC) 하위에 들여쓰기되어 출력됩니다.

### 💡 문자 간격, 글자 강조 및 코드 칩 배지
- **띄어쓰기 및 줄바꿈**: 문단 사이에 빈 줄을 하나 넣으면 적절한 문단 간격이 자동으로 부여됩니다.
- **백틱(`` ` ``) 인라인 코드**: 문장 사이에서 백틱으로 단어를 감싸면 `Python`이나 `FastAPI`처럼 귀엽고 강한 오렌지/앰버 색상의 칩 배지로 스타일링됩니다.
- **리스트 Bullet**: 마크다운에서 `-` 또는 `1.`로 리스트를 작성하면 Bullet 아이콘이 포인트 블루 컬러(`--color-primary`)로 칠해져 시선을 잡아줍니다.

## 4. 프로젝트 슬라이드(캐러셀 갤러리) 이미지 연결 가이드

프로젝트 상세 페이지 하단에 보여지는 좌우 애니메이션 캐러셀 갤러리는 **동적 로딩(Astro Glob)**을 통해 렌더링됩니다.

- **이미지 배치 폴더**: 해당 프로젝트 이름과 관련된 이미지 디렉토리에 사진을 넣고 스키마의 `thumbnail`에 폴더 내 이미지 파일 경로를 올바르게 명시하세요.
- **캐러셀 인식 방식**: `src/components/ProjectCarousel.astro`는 `1.jpg`, `2.jpg` 등 일정한 네이밍 패턴이나 폴더 규칙을 기준으로 갤러리 이미지를 깔끔하게 롤링해 보여줍니다.

## 5. 목차(Table of Contents) 스마트 퀵 이동 버튼

포스팅 우측 측면(또는 본문 상단 박스)에 렌더링되는 목차 UI에는 강력한 UX 편의 기능이 내장되어 있습니다.

- **'ON THIS PAGE' / '목차' 타이틀 클릭 시 최상단 이동 (`data-toc-scroll-top`)**:
  목차 메뉴 상단의 `ON THIS PAGE`(스크롤 목차) 또는 `목차`(박스형 목차) 타이틀 영역을 누르면 마우스 호버 시 작은 화살표 아이콘(↑)이 위로 들리며, 클릭하는 즉시 **스무스 스크롤 효과와 함께 페이지 최상단으로 즉각 복귀**합니다.
