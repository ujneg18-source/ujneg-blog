# Phase: 태그 전용 페이지(SSG) 및 공통 컴포넌트 분리

## 1. 작업 배경 및 목표
- 기존 `/tags` 단일 페이지에서 클라이언트 JS로 필터링하던 방식을 폐기하고, 각 태그별 고유 주소를 갖는 정적 라우팅 페이지(`/tags/[tag]`)를 신규 생성합니다.
- 태그 상세 페이지 역시 페이지네이션이 필요하므로, Notes 작업 시 사용되는 페이지네이션 로직과 완전히 동일한 방식으로 `getStaticPaths + paginate()`를 적용합니다.
- Notes 목록과 Tags 목록에서 UI 중복이 발생하지 않도록, **포스트 카드(NoteCard)**와 **페이지네이션(Pagination)**을 공통 컴포넌트로 추출하여 재사용성을 극대화합니다.

## 2. 사전 검증 및 라우팅 슬러그 원칙 확정

### 2.1. 한글 및 공백 태그 파라미터 빌드 검증 (완료)
- `src/pages/test/[tag].astro` 테스트용 동적 라우팅 파일을 임시로 생성하여 **실제 빌드(`npm run build`) 테스트를 진행**했습니다.
- 테스트 결과, Astro 빌드 시스템이 `params: { tag: "웹" }` 및 `params: { tag: "데이터 엔지니어링" }` 과 같은 한글과 공백이 포함된 문자열을 문제없이 파싱하여 `/test/웹/index.html` 폴더 구조로 **정상 빌드**해내는 것을 확인했습니다.
- **결론**: 별도의 복잡한 영문 슬러그 매핑 테이블이나 소문자 변환 로직 없이, **태그명 그대로(원본 문자열)를 라우트 파라미터로 사용**하기로 확정합니다. 브라우저에서 자동으로 URL 인코딩 처리되며 완벽하게 동작합니다.

## 3. 구현 계획 상세

### 3.1. 공통 UI 컴포넌트 추출
- **`src/components/NoteCard.astro`**: 
  기존 `notes.astro`에 있는 포스트 카드 디자인(좌측 썸네일 + 우측 텍스트)을 컴포넌트화합니다. Astro Content Collection(`CollectionEntry<'notes'>`) 데이터를 prop으로 받아 렌더링합니다.
- **`src/components/Pagination.astro`**:
  Astro의 `Page` 객체를 prop으로 받아, 이전/다음 화살표 및 현재 페이지 번호를 렌더링하는 공통 컴포넌트입니다.

### 3.2. 태그 상세 페이지 생성 (`src/pages/tags/[tag]/[...page].astro`)
- **라우팅 규칙**: 한글 및 띄어쓰기를 포함한 원본 태그명을 그대로 라우트 파라미터로 사용합니다 (예: `/tags/웹`, `/tags/Data Engineering`).
- **`getStaticPaths`**: 
  - `getCollection('notes')`로 모든 글을 불러와 존재하는 모든 태그의 고유 목록을 추출합니다.
  - 각 태그별로 글을 필터링한 후 `paginate()`를 호출하여 페이지 경로를 생성합니다 (페이지 당 4개).
- **페이지 UI 구성**:
  - 상단 좌측: `#태그명` 타이틀과 해당 태그가 포함된 총 글 개수(배지 형태).
  - 상단 우측: `모든 태그 →` (링크: `/tags`)
  - 본문: `NoteCard` 컴포넌트를 반복 렌더링.
  - 하단: `Pagination` 컴포넌트 렌더링.

### 3.3. 기존 Tags 페이지(`/tags`) 개편
- 하단의 'Tag Cloud' 영역에서 태그 뱃지를 클릭하면, JS로 DOM을 숨기는 대신 `<a href="/tags/[태그명]">` 링크를 통해 태그 전용 페이지로 즉시 이동하도록 로직을 수정합니다.
- 클라이언트 필터링 JS 코드를 모두 제거하여 페이지를 가볍고 SEO 친화적으로 만듭니다.

## 4. 변경 예정 파일 목록
- **[NEW]** `src/components/NoteCard.astro`: 포스트 카드 공통 컴포넌트
- **[NEW]** `src/components/Pagination.astro`: 페이지네이션 공통 컴포넌트
- **[NEW]** `src/pages/tags/[tag]/[...page].astro`: 태그 전용 상세 페이지
- **[MODIFY]** `src/pages/tags.astro`: JS 필터링 로직 제거 및 앵커 링크 적용
- **[MODIFY]** `src/pages/notes/[...slug].astro`: `NoteCard`, `Pagination` 공통 컴포넌트 활용

## 5. 확인 및 검증 계획
1. `/tags` 페이지에서 임의의 태그 클릭 시 `/tags/[원본태그명]` 페이지로 정상 이동하는지 확인.
2. 태그 상세 페이지 상단에 `#태그명`과 글 개수 배지가 올바르게 표시되는지 확인.
3. 태그 상세 페이지에 할당된 글이 4개를 초과할 경우 페이지네이션이 정상 동작하는지 검증.
4. "모든 태그 →" 링크 클릭 시 `/tags` 페이지로 정상 복귀하는지 확인.
