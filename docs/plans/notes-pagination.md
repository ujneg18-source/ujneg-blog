# Phase 1: Content Collection 기반 Notes 페이지네이션 및 다층 카테고리 라우팅

## 1. 작업 배경 및 목표
- JS 객체 더미 데이터 대신, 실제 운영 환경과 동일한 **Astro Content Collection** 구조를 처음부터 도입합니다.
- 기존에 구현된 **Tags 페이지**와 **Pagefind 검색**의 컨벤션을 완벽히 분석하여 데이터 구조를 100% 호환되도록 맞춥니다.
- 카테고리 필터(대분류 및 소분류)와 페이지네이션이 충돌하지 않고 안정적으로 동작하도록 Astro 정적 라우팅(`[...slug].astro`)을 활용하여 구축합니다.

## 2. 발생 이슈 및 해결 방법 1 (Astro paginate() 에러)
- **이슈**: `src/pages/notes/[...slug].astro`에서 Astro 내장 `paginate()` 유틸리티를 사용했을 때, 라우트 파일명에 `page` 파라미터가 없다는 이유로 에러가 발생했습니다.
- **해결 방안**: **수동 페이지네이션 로직(`generatePaginatedPaths`)**을 직접 구현하여 기존 UI와 100% 호환되도록 구성했습니다.

## 3. 발생 이슈 및 해결 방법 2 (빈 컬렉션 에러 - ALL NOTES LENGTH: 0)

### 3.1. 원인 분석
- 현재 프로젝트의 Astro 버전이 5.0 이상(v7.1.3 표기)이었습니다. 
- 최신 Astro에서는 Content Collections API가 크게 변경되어 구버전 방식인 `src/content/config.ts` 및 `type: 'content'` 스키마를 완전히 무시하고 읽지 않는 문제가 있었습니다.
- 프로젝트를 분석해 보니 이미 최상단 경로에 최신 규격인 `src/content.config.ts`가 존재했고, 이 곳에 기존 `blog` 컬렉션이 `loader: glob(...)` 문법으로 작성되어 있었습니다.

### 3.2. 해결 방법
1. Astro가 무시하고 에러를 발생시키던 구버전 스키마 파일(`src/content/config.ts`)을 완전히 **삭제**했습니다.
2. 기존에 존재하던 `src/content.config.ts`를 열어, 기존 `blog` 컬렉션 코드를 **안전하게 그대로 유지**한 상태에서 아래와 같이 최신 `glob` 로더 기반의 `notes` 컬렉션을 이어붙였습니다.
3. 마크다운 더미 파일 5개는 스키마와 완벽히 호환되므로 별도로 수정하지 않았습니다.

### 3.3. 검증 결과
- 수정 즉시 `npm run dev` 로그에서 컬렉션 에러가 완전히 사라졌습니다.
- 브라우저 `/notes` 페이지에서 사이드바 카테고리 숫자가 정상적으로 렌더링되는 것을 확인했습니다.

# Phase 3: Notes 상세 페이지 디자인 전면 개편 및 기능 고도화 (진행 예정)

## 1. 개편 목표 및 요약
참고자료(디자인 스크린샷 1~4)를 기반으로 Notes 개별 글 상세 페이지(`/notes/[id]`)를 세련되고 가독성 높은 인터페이스로 대대적으로 개편합니다.

> [!IMPORTANT]
> - **좌측 정렬 구조 변경**: 헤더(카테고리/날짜/제목)를 시원한 좌측 정렬 배치로 변경하고 가독성 최적의 폭(max-width 760px)으로 맞춥니다.
> - **계층형 목차(TOC) 박스**: 마크다운 본문 시작 전, `h2`, `h3` 헤딩 계층을 인지하여 스무스하게 앵커 이동하는 박스형 목차를 삽입합니다.
> - **우측 Sticky 반응형 목차**: 데스크탑 화면에서는 본문 스크롤에 맞춰 활성 글자가 하이라이트되는 고정 목차를 우측에 배치하며, 모바일에서는 상단 목차 박스만 노출되게 처리합니다.
> - **관련 글 카드 리스트**: 태그 뱃지 하단에 같은 소분류(또는 대분류)에 해당하는 다른 글 목록 박스를 추가하며, **'현재 글'** 텍스트를 강조해 표시합니다.
> - **맨 위로 가기 버튼**: 스크롤 감지형 우측 하단 플로팅 '↑' 화살표 버튼을 삽입합니다.

## 2. 상세 구현 계획

### 2.1. TOC 컴포넌트 신규 개발
#### [NEW] [TableOfContents.astro](file:///c:/Users/Playdata/Desktop/ujneg-blog/src/components/TableOfContents.astro)
- Astro의 기본 기능인 `await render(post)`가 제공하는 `headings` 배열(`[{ depth, slug, text }]`)을 Props로 받아서 렌더링합니다. 별도의 수동 마크다운 파싱이나 복잡한 플러그인 설치 없이 Astro 네이티브 앵커(`id`) 기능과 즉각 호환됩니다.
- **`variant="box"` (본문 상단 박스형)**:
  - 테두리 및 그림자 효과를 가진 세련된 박스 디자인.
  - `h2(depth: 2)`는 `> # 제목`, `h3(depth: 3)`는 `- 소제목` (들여쓰기 1.5rem Applied) 형태로 출력.
- **`variant="sticky"` (우측 데스크톱 고정형)**:
  - `hidden xl:block` 반응형 처리를 통해 큰 화면(1280px 이상 등)에서 본문 외부 우측 영역에 Sticky 형태로 위치.
  - `IntersectionObserver` 자바스크립트를 포함하여 현재 사용자가 읽고 있는 섹션에 시각적 포커싱(primary 컬러 변경 및 볼드 처리) 진행.
