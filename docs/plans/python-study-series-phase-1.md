# Python 학습 시리즈 정리 계획

## 목표

`SKN31_JY/01_python`의 Jupyter Notebook 필기를 원본 흐름과 표현을 최대한 보존하면서 블로그에서 읽기 좋은 Python 기초 시리즈로 옮긴다.

## 편집 원칙

- 원본 Notebook 하나를 기본적으로 글 하나로 유지한다.
- 제목은 `원본 주제: 구체적인 부제` 형식을 사용한다.
- Markdown 필기와 코드 셀은 보존한다.
- Notebook 실행 출력은 첫 변환에서 제외한다.
- 원본의 H1 제목은 블로그 본문의 H2로 내려 페이지당 H1을 하나만 유지한다.
- 원본 Notebook 파일명과 시리즈 순서를 frontmatter에 기록한다.
- 이미지 참조는 `/images/python/` 아래의 정적 자산으로 옮긴다.
- 강의자료를 그대로 옮긴 부분은 공개 전에 개인적인 설명과 출처 표기를 검토한다.

## 1차 콘텐츠

1. Python 개요: 프로그램과 REPL 실행 방식
2. 변수와 데이터 타입: 객체, 할당, 연산 이해하기
3. 자료구조: List·Tuple·Dictionary·Set 정리
4. 제어문과 Comprehension: 조건·반복·간결한 표현
5. 함수: Parameter·Argument·Return 이해하기
6. 객체지향 프로그래밍: 클래스·상속·특수 메서드
7. Module과 Package: import, pip, uv 사용법
8. 예외 처리: 오류를 다루고 사용자 정의 예외 만들기
9. 입출력: 파일, bytes, 객체 직렬화
