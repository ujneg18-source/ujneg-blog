## 왜 라이브러리 대신 직접 구현했나?
웹 개발에서 가장 자주 쓰이면서도 동시에 가장 골치 아픈 UI 컴포넌트 중 하나가 바로 **캐러셀 슬라이더(Carousel Slider)**입니다. `Slick.js`나 `Swiper`처럼 훌륭하고 거대한 오픈소스 라이브러리가 존재하지만, 단순히 프로젝트 스크린샷 2~3장을 좌우로 넘겨주는 가벼운 인터페이스를 위해 수십 KB의 JS 번들과 CSS를 포함시키는 것은 낭비라고 여겨졌습니다.

### 바닐라 JS 슬라이더 구현의 핵심 난제
- **무한 루프의 착시 (Cloning Trick)**: 1번 슬라이드와 마지막 슬라이드 경계면에서 스와이프할 때 뒤돌아오는 끊김 없이 마치 뫼비우스의 띠처럼 영원히 회전하는 듯한 시 시각적 일각을 만들어내야 합니다.

## 해결책: 덤 슬라이드(Clone) 복제 전략
가장 매끄러운 무한 롤러코스터 효과를 달성하기 위해 **앞과 뒤에 슬라이드 복제본(Clone Node)을 붙여넣는 기법**을 설계했습니다.

### 작동 메커니즘
1. 만약 실제 슬라이드가 `[A, B, C]` 3장이라면, DOM 트리 초기화 단계에서 `[C', A, B, C, A']`로 5개 배열을 가상으로 확장합니다.
2. 유저가 마지막 `C` 슬라이드에서 다음 버튼을 클릭하면 자연스럽게 transition animation과 함께 `A'` 복제본을 향해 부드럽게 화면이 밀려납니다.
3. animation TransitionEnd 이벤트 리스너가 발동하는 찰나, 0초(`transition: none;`)만에 실제 진짜 1번 `A` 슬라이드 위치로 transform 좌표를 쥐도 새도 모르게 순식간에 복구합니다.
4. 사용자의 시야에는 이 마법 같은 프레임 스위치 장면이 전혀 느껴지지 않고 끊임없이 순환하는 완벽한 슬라이드가 완성됩니다!
