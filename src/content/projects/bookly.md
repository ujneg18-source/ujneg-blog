## 1. 서비스 기획 및 목표
Bookly는 책과의 만남을 더욱 깊이 있고 유의미하게 남기고자 고안된 **개인 맞춤형 독서 기록 및 AI 도서 추천 서비스**입니다. 종이에 휘발되는 독서 메모 대신, 내장된 문장 하이라이팅 저장 체계와 해시태그 네트워크 분석으로 독자의 성향에 꼭 맞는 다음 시나리오의 도서를 큐레이션합니다.

### 주요 제공 가치
- **문장 캡처 및 클라우드 동기화**: 밑줄 친 글귀를 간차적으로 타이핑 또는 캡처하여 클라우드 서재에 구조적으로 스크랩
- **독서 통계 및 지표 도식화**: 연간/월간 독서율 및 카테고리 (인문, IT, 철학 등) 편향성을 레이더 차트로 시각화

## 2. 사용자 맞춤형 도서 추천 알고리즘
단순 베스트셀러 위주의 나열을 탈피하고자 **협동 필터링 (Collaborative Filtering)** 기반 및 독자의 서평 감정성 텍스트를 조합한 혼성 알고리즘을 도입했습니다.

### 협동 필터링 모델 적용
- 유저별 읽은 책 기록과 5점 만점 평가 평점을 행렬(User-Item Matrix)로 구성
- 코사인 유사도(Cosine Similarity)를 산출하여 취향 군집이 유사한 사용자가 열광한 숨겨진 명작을 1순위로 추천

## 3. 풀스택 개발 및 성능 최적화
웹 생태계의 모범 규칙에 입각하여 프론트 및 API 전체를 **Next.js (App Router)** 와 **TypeScript** 기반으로 개발했습니다. DB 구조는 독서 노트처럼 스키마 유연성이 높은 **MongoDB**와 Mongoose를 차용했습니다.

### SSR/ISR 기반 페이지 최적화
- 책 상세 정보 및 큐레이션 메인 홈은 ISR(Incremental Static Regeneration)을 적용하여 정적 페이지급 속도(TTFB 평균 120ms 이하) 달성
- 개인별 커스텀 대시보드만 클라이언트 사이드 렌더링(CSR)으로 동적 구동

### 트러블슈팅: 무한 스크롤 조회 시 렌더링 부하 완화
- **문제 현상**: 도서관 탭에서 누적된 문장 인용록을 스크롤할 때마다 DOM 노드 기하급수적 증가 및 메모리 누수 발생
- **해결 방안**: React Virtualized 윈도우 렌더링 및 IntersectionObserver를 활용한 정밀 lazy load 로직 구현으로 화면에 보이는 최대 20개 노드만 DOM 트리에 상주하도록 리팩토링
