## 인공지능(AI)이란

노트북 맨 위에 적은 한 줄 요약이다.

```text
인공지능의 구현법(알고리즘)
- 머신러닝 > 딥러닝(LLM)
```

- **지능**: 어떤 문제를 해결하기 위한 지적 활동 능력
- **인공지능**: 기계가 사람의 지능을 모방하게 하는 기술
  - 구현 방식은 크게 **규칙 기반**과 **데이터 학습 기반**으로 나뉜다

```text
데이터 학습기반 => 머신러닝
규칙 기반 => IF THAN ELSE (조건 RULE 제공)
```

> **보충** 메모의 `IF THAN ELSE`는 `IF THEN ELSE`다.

용어는 1955년 다트머스대학의 존 매카시(John McCarthy)가 처음 제안했다. 인간의 지능(인지, 추론, 학습 등)을 컴퓨터나 시스템으로 만든 것, 또는 그 방법론과 실현 가능성을 연구하는 기술·과학을 말한다.

규칙 기반과 데이터 기반의 차이는 수업에서 이렇게 적었다.

```text
규칙기반 => 전문가시스템/80년대 폐기
* 모든 규칙이 들어가나, 예외적으로 규칙이 빠지거나, 시간이 지나서 법이 바뀌면, 지속적으로 업데이트해야함

데이터기반 (*데이터 폭증으로 발전*)
```

규칙 기반은 사람이 모든 규칙을 넣어야 하니 예외가 생기거나 상황이 바뀔 때마다 사람이 고쳐야 한다. 데이터 기반은 규칙을 데이터에서 찾게 하는 방식이고, 쓸 수 있는 데이터가 폭증하면서 발전했다.

### AGI (Artificial General Intelligence)

- **정의**: 인간처럼 광범위한 지적 과제를 수행할 수 있는 인공지능. 새로운 문제도 사전 학습 없이 유연하게 사고·학습·판단할 수 있다
- **현재 AI와의 차이**: 지금의 AI(Narrow AI)는 특정 목적만 수행한다(알파고는 바둑, DALL·E는 이미지 생성). AGI는 하나의 시스템으로 모든 작업을 수행하는 범용 지능이다
- **개발의 어려움**: 추상적 사고·감정 이해·윤리 판단을 기술로 구현하기 어렵고, 데이터 편향·안정성·**설명 가능성** 문제가 남아 있다
- **사회적 영향**: 기후·신약·우주 같은 복잡한 문제 해결과 생산성 향상이 기대되는 한편, 일자리 대체, 의사결정 권한 이전, 불평등 심화, 책임 소재 같은 법적 공백이 우려된다

설명 가능성에 대해 따로 메모를 남겼다.

```text
설명가능성 => 근거를 제공하지 않음
ex. 결과(예측)은 잘하지만, 근거를 만들지는 못함. (why)
00점에 영업점을 개설하면 성공 가능성이 높다. BUT 왜를 설명못함 , ex. 전쟁 의사결정 // 법, 제도로 뒤받침해야 함.
```

예측은 잘 맞혀도 **왜** 그런지 설명하지 못하면 중요한 의사결정에 그대로 쓰기 어렵다. 그래서 법과 제도가 받쳐 줘야 한다는 이야기였다.

### 인공지능 발전의 주요 원동력

1. **데이터 폭증(Big Data)**: 인터넷, 스마트폰, IoT에서 쏟아지는 데이터로 학습할 데이터가 충분해졌다
2. **컴퓨팅 파워 향상**: 병렬 연산에 특화된 GPU, TPU
3. **딥러닝 알고리즘 혁신**: CNN(이미지), RNN/LSTM(시계열), Transformer(언어). 2017년 "Attention is All You Need" 논문의 Transformer가 LLM 시대를 열었다
4. **오픈소스 생태계**: PyTorch, TensorFlow, Hugging Face. 공개된 모델(Stable Diffusion, LLaMA 등)을 바탕으로 더 나은 모델이 나오는 선순환
5. **빅테크의 투자 경쟁**
6. **생성형 AI 대중화와 사용자 피드백**: ChatGPT 사용자 피드백이 RLHF 같은 기법 발전으로 이어졌다

## 머신러닝과 딥러닝

![인공지능, 머신러닝, 딥러닝의 관계와 시기](/images/ml/fig-ai-ml-dl.png)

*출처: [NVIDIA 블로그](https://blogs.nvidia.co.kr/2016/08/03/difference_ai_learning_machinelearning/)*

인공지능 안에 머신러닝이 있고, 머신러닝 안에 딥러닝이 있다.

- **머신러닝**: 데이터 학습 기반의 인공지능 분야. 명시적인 규칙을 프로그래밍하지 않아도 데이터에서 패턴을 학습해 예측하거나 분류한다
- **딥러닝**: 인공신경망 알고리즘을 기반으로 하는 머신러닝의 한 분야. **비정형 데이터(영상, 음성, 텍스트)** 에서 뛰어난 성능을 낸다. 단 학습 데이터가 많아야 한다

```python
# ex) 데이터를 가지고, 규칙을 찾기, 예를 들어, 마케팅
# 데이터를 가지고, 고객이 어떤 상품을 구매하는지, 어떤 상품을 구매할 확률이 높은지, 이런 것을 분석하는 것
# 문제는 시간에 따라 고객의 행동이 달라질 수 있다는 것, 그래서 과거 데이터를 가지고 미래를 예측하는 것이 어려울 수 있다는 것
# 그래서 머신러닝에서는 데이터를 가지고 모델을 만들고, 그 모델을 가지고 미래를 예측하는 것이 중요하다.
# 먼저 알고리즘을 구현하고 거기에 데이터를 넣는다.
```

### 정형 데이터와 비정형 데이터

| | 뜻 | 예 |
|---|---|---|
| **정형 데이터** | 미리 정해 놓은 형식과 구조에 따라 저장된 데이터 | 관계형 데이터베이스의 테이블 |
| **비정형 데이터** | 정해진 규칙 없이 저장되어 값의 의미를 바로 파악하기 어려운 데이터 | 텍스트, 영상, 음성 |

```python
# RDBMS는 관계형 데이터베이스 관리 시스템, SQL을 사용해서 데이터를 관리하는 시스템
# RDB란 정형데이터(표데이터)를 저장하는 데이터베이스, RDBMS는 RDB를 관리하는 시스템
```

비정형 데이터가 왜 어려운지는 댓글 감정 분석을 예로 적었다.

```python
# 비정형 데이터 => 자연어 - 댓글 (감정, 부정적, 긍정적), 이미지 - 사진 (고양이, 강아지), 음성 - 소리 (사람의 목소리, 음악)
# 데이터 판단 모델을 하나 만들고, 텍스트를 긍정, 부정으로 나눠서 의사결정 모델로 활용한다.
# but 쉽지 않음. 예시) 단어30개, 긍정적 단어 15개, 부정적 단어 15개, 텍스트에 긍정적 단어가 10개, 부정적 단어가 5개 있으면 긍정적이라고 판단하는 모델을 만들 수 있지만, 실제로는 그렇게 간단하지 않음.
# 댓글은 쓰는 사람마다 다르고, 같은 단어라도 상황에 따라 긍정적이 될 수도 있고 부정적이 될 수도 있기 때문에, 모델을 만드는 것이 어렵다. 그래서 머신러닝에서는 데이터를 많이 가지고 모델을 만들어야 한다.
# 이러한 비정형데이터를 잘 다루는 것이 딥러닝
# 머신러닝과 딥러닝의 차이점은, 머신러닝은 데이터를 가지고 모델을 만드는 것이고, 딥러닝은 데이터를 가지고 모델을 만드는 것과 동시에 모델이 스스로 학습하는 것이다.
# 딥러닝에서는 모델이 스스로 학습하기 때문에, 단, 데이터가 많아야 한다. 그래서 딥러닝에서는 데이터가 많아야 한다. 최소 몇십만개 데이터를 가지고 모델을 만들어야 한다.
```

> **보충** 머신러닝도 데이터로 "스스로 학습"하기는 마찬가지라, 둘의 차이는 **무엇을 사람이 정해 주느냐**로 보는 편이 정확하다. 전통적인 머신러닝은 사람이 표의 컬럼 같은 feature를 만들어 넣고, 딥러닝은 픽셀·단어 같은 원본에 가까운 입력에서 쓸 만한 특징(표현)까지 신경망이 학습한다. "최소 몇십만 개"도 정해진 기준은 아니다. 처음부터 학습하면 데이터가 많이 필요하지만, 이미 학습된 모델을 가져와 조금 더 학습시키는 방식(전이 학습, 파인튜닝)은 수천 개 수준으로도 쓸 만한 결과가 나온다.

## 전통적인 프로그래밍과 머신러닝의 차이

![전통적 프로그래밍과 머신러닝 비교](/images/ml/fig-traditional-vs-ml.png)

- **전통적인 프로그래밍**: 데이터를 처리하는 규칙(함수, 알고리즘)을 **사람이** 찾아서 작성한다
- **머신러닝**: 데이터를 처리하는 규칙을 주어진 데이터에서 **컴퓨터가** 직접 찾도록 한다

이 부분에 메모가 가장 길다. 입력과 출력의 예시를 여럿 적어 뒀다.

```python
# 머신러닝에의 목표: 기존의 데이터를 통해 입출력의 관계를 추정하는 모델을 만드는 것
# 과거의 데이터를 통해 예측 또는 추론
# 데이터의 패턴을 보고 데이터의 맞는 알고리즘을 찾는다
# 입력 => 예측 공식(알고리즘=모델=모형) => 출력(예측결과)
# 예시) 고객의 나이, 성별, 구매이력 => 고객이 어떤 상품을 구매할 확률이 높은지 예측하는 모델을 만드는 것
# 예시) 코스피 지수, 환율, 금리 => 주식 가격 예측 모델을 만드는 것
# 예시) 환자 나이, 성별, 혈압, 콜레스테롤 수치 => 환자가 심장병에 걸릴 확률이 높은지 예측하는 모델을 만드는 것
# 예시) 학생의 공부 시간, 출석률, 과제 제출 여부 => 학생의 성적 예측 모델을 만드는 것
# 예시) 텍스트 데이터 => 긍정적, 부정적 예측 모델을 만드는 것 //카톡 오픈 채팅방에서 긍정적, 부정적 예측 모델을 만드는 것
# 예시) 이미지 데이터 => 고양이, 강아지 예측 모델을 만드는 것
# 예시) 음성 데이터 => 사람의 목소리, 음악 예측 모델을 만드는 것

# 모형이란 입력값에 따른 출력값을 예측해서 알고리즘 공식을 만든 것 (즉 함수 형태로 만들어진 것)
# 입력값과 출력값의 관계

# 머신러닝의 종류
# - 지도학습 (Supervised Learning)
# - 비지도학습 (Unsupervised Learning)
# - 강화학습 (Reinforcement Learning)
```

## 머신러닝 모델

**모델**은 데이터를 기반으로 입력(Feature)과 출력(Target)의 관계를 추정하는 **함수**다. 이 함수로 예측(prediction)이나 추론(inference)을 한다.

- 머신러닝은 이 함수를 데이터 학습으로 정한다
- 데이터 학습이란 "이 데이터는 이런 패턴을 가졌을 것"이라고 가정한 일반화된 함수를 정한 뒤, 그 함수의 **파라미터**를 데이터에 맞춰(fitting) 함수를 완성하는 것이다. 이 과정을 "모델을 학습시킨다"고 한다
- 모델(모형)의 본래 뜻은 **현실(또는 데이터)의 구조를 단순화해 표현한 것**이다

![모델은 입력 X를 출력 Y로 바꾸는 함수 f](/images/ml/fig-model-yfx.png)

**머신러닝이란 입력변수와 출력변수 사이의 패턴(함수)을 데이터 학습으로 만드는 것**이다.

모델을 만드는 과정은 세 단계다.

1. 모델을 정해 수식화한다
2. 데이터로 모델을 **학습(Train)** 시킨다. 모델을 데이터의 패턴에 맞춘다(fit)
3. 학습된 모델이 데이터 패턴을 얼마나 잘 표현하는지 **평가(Test)** 한다

## 데이터셋 구성

| 용어 | 뜻 | 표기 |
|---|---|---|
| **Feature** (특성, 피처) | 모델이 학습에 쓰는 **입력 변수**. 데이터의 특성·속성값 | `X` |
| **Label** (레이블, 정답) | 모델이 예측해야 할 **정답값**(출력 변수). Target이라고도 한다 | `y` |
| **Data Point** | 데이터 하나(sample). 테이블 데이터라면 **행** 하나. Instance, 관측값(Observation)이라고도 한다 | |

![Iris 데이터로 본 Feature와 Label](/images/ml/fig-feature-label-1.png)

![이미지 데이터의 Feature와 Label](/images/ml/fig-feature-label-2.png)

```python
# 세토사, 버시컬러, 버지니카 - 꽃받침 길이, 꽃받침 너비, 꽃잎 길이, 꽃잎 너비 => 세 가지 품종 예측 모델을 만드는 것 => 지도학습
# 품종별로 데이터의 패턴이 다르기 때문에, 차이의 데이터를 가지고 모델을 만들 수 있다.
# BUT, 적절하지 않은 피처, 입력값이라면 모델이 잘 만들어지지 않을 수 있다. 그래서 피처 엔지니어링이 중요하다.
# 우리가 원하는 정확한 값을 얻는 알고리즘을 만들려면 패턴을 만들기위해 좋은 데이터를 선별해야 함

# 사진이 고양이인지 강아지인지 예측하는 모델을 만드는 것 => 지도학습
# 사진안에 있는 픽셀들이 피처가 됌
# 지도학습 => 입력과 출력이 있는 데이터가 필요함 (입력: 사진, 출력: 고양이/강아지)
```

표 데이터라면 컬럼이 feature이고, 이미지라면 픽셀 값 하나하나가 feature다. 품종마다 꽃잎·꽃받침 크기의 패턴이 다르기 때문에 그 차이로 품종을 가르는 모델을 만들 수 있다. 반대로 정답과 관계없는 feature만 있으면 아무리 학습해도 모델이 잘 나오지 않는다.

## 머신러닝 알고리즘 분류

### 지도학습 (Supervised Learning)

모델에게 Feature와 **정답(Label)** 을 함께 주며 학습시킨다. 대부분의 머신러닝이 지도학습이고, 분류와 회귀로 나뉜다.

- **분류(Classification)**: 두 개 이상의 클래스(범주) 중 하나를 고르는 문제
  - **이진 분류**: 맞다/아니다 두 가지 중 하나 (스팸인가?)
  - **다중 분류**: 여러 클래스 중 하나 (setosa / versicolor / virginica)
- **회귀(Regression)**: **숫자(연속된 값)** 를 예측하는 문제 (집값, 주가)

```python
# 개/고양이(50%)
# 주가(0~무한대)
# 회기보다 분류가 더 쉽다. 주가의 가격을 예측하는 것은 회기, 고양이/강아지 예측하는 것은 분류
# 가격보다 가격대로 예측하는 것이 더 쉽다.
# 분류는 이 모델이 몇%의 정확도를 가지고 판단
# 회기는 이 모델이 몇%의 오차를 가지고 있는지 판단

# 이진분류 => 맞냐 틀리냐
# 다중분류 => 고양이, 강아지, 토끼 => 3개 이상의 클래스를 예측하는 모델을 만드는 것
# 회기분류 => 주가 예측, 날씨 예측 => 연속적인 값을 예측하는 모델을 만드는 것 (정확한 값 예측 어려움)
```

> **보충** 메모의 "회기"는 모두 **회귀**(回歸, Regression)다. 마지막 줄의 "회기분류"도 분류의 한 종류가 아니라 **회귀** 문제를 말한 것이다. 다중 분류도 정확히는 "2개보다 많은 클래스"이고, 개/고양이/토끼처럼 3개 이상이면 다중 분류다.

정리하면 분류는 **몇 %나 맞혔나**(정확도)로, 회귀는 **얼마나 틀렸나**(오차)로 평가한다. 가격 그 자체보다 "가격대"를 맞히는 게 쉽다는 메모는 회귀 문제를 구간으로 묶어 분류 문제로 바꾸는 발상이다.

### 비지도학습 (Unsupervised Learning)

**정답 없이** 데이터의 특징만으로 데이터 사이의 관계를 찾는다.

- **군집(Clustering)**: 비슷한 데이터끼리 그룹을 찾는다. 데이터 경향성을 파악할 때 주로 쓴다
- **차원축소(Dimensionality Reduction)**: 예측에 영향을 최대한 주지 않으면서 feature 수를 줄인다. 고차원 데이터를 저차원으로 바꾼다

```python
# 비지도학습이란 정답(출력값)이 없는 데이터를 가지고 모델을 만드는 것
# 예시) 고객의 나이, 성별, 구매이력 => 고객을 몇개의 그룹으로 나눌 수 있는지 예측하는 모델을 만드는 것
# 자주 사용하는 비지도학습 알고리즘 => K-평균 군집화, 계층적 군집화, DBSCAN, PCA(차원축소)
# 텍스트 데이터 => 텍스트를 몇개의 그룹으로 나눌 수 있는지 예측하는 모델을 만드는 것

# 차원축소 => 피처가 너무 많아서 모델이 잘 만들어지지 않을 때, 피처를 줄이는 것//컬럼의 갯수를 줄이는 것
# 필요한 정보를 위한 피처를 최대한 유지하면서 불필요한 피처를 제거하는 것
```

> **보충** 차원축소는 컬럼을 골라서 버리는 것(feature 선택)과 조금 다르다. PCA 같은 방법은 기존 컬럼들을 **조합해 새 축**을 만들고, 정보가 많은 축 몇 개만 남긴다. 그래서 남은 값이 원래 컬럼 하나와 일대일로 대응하지 않는다.

데이터 이해와 준비 단계에 메모를 많이 남겼다.


## 정리

- 인공지능은 **규칙 기반**과 **데이터 학습 기반**으로 나뉘고, 데이터 학습 기반이 머신러닝, 그 안의 신경망 기반이 딥러닝이다
- 머신러닝은 입력(Feature, `X`)과 출력(Label, `y`)의 관계를 **데이터로 찾은 함수(모델)** 다
- 정답이 있으면 **지도학습**(분류·회귀), 없으면 **비지도학습**(군집·차원축소)
- 개발은 문제 정의 → 데이터 이해 → 전처리 → 모델링 → 평가 → 배포 순으로, 평가 결과에 따라 앞 단계를 반복한다
- 파이썬 머신러닝은 scikit-learn이 표준이고, 모든 모델이 같은 사용법(`fit`, `predict`)을 따른다
