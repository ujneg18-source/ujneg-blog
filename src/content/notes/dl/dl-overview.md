## 인공지능 (AI)

- **지능**: 어떤 문제를 해결하기 위한 지적 활동 능력
- **인공지능**: 기계가 사람의 지능을 모방하게 하는 기술. 규칙 기반과 데이터 학습 기반으로 나뉜다

### Strong AI와 Weak AI

- **AGI** (Artificial General Intelligence): 인간이 할 수 있는 모든 지적 업무를 해낼 수 있는 (가상의) 기계 지능. 인공지능 연구의 주요 목표다
- **Strong AI (강 인공지능)**: AGI 수준의 성능을 가지는 인공지능. 연구가 목표하는 방향이다
- **Weak AI (약 인공지능)**: 사람은 쉽게 하지만 컴퓨터로는 어려웠던 일을 컴퓨터가 하도록 하는 것이 목적이다. 지각(知覺)이 없고 **특정한 업무**에 집중한다

지금 우리가 쓰는 번역기, 이미지 분류기, 챗봇은 모두 약 인공지능에 속한다.

### 인공지능 발전을 가능하게 한 세 가지

| 요소 | 내용 |
|---|---|
| **데이터의 급격한 증가** | 디지털 사진, 동영상, IoT, SNS로 데이터가 폭발적으로 늘었다 |
| **알고리즘의 발전** | 늘어난 데이터로 기존 알고리즘이 개선되고 새 알고리즘이 나왔다 |
| **하드웨어의 발전** | CPU, 특히 **GPU**의 발전이 딥러닝 발전으로 이어졌다. 구글은 딥러닝 전용 칩 TPU를 만들었다 |

## 머신러닝과 딥러닝

- **머신러닝**: 동작을 일일이 코드로 명시하지 않고, 데이터로 학습하게 하는 알고리즘과 기술을 개발하는 인공지능 분야
- **딥러닝**: **인공신경망** 알고리즘을 기반으로 하는 머신러닝의 한 분야. **비정형 데이터**(영상, 음성, 텍스트)에서 뛰어난 성능을 낸다. 단 학습 데이터가 많아야 한다

| | 정형 데이터 | 비정형 데이터 |
|---|---|---|
| 형태 | 표(table)처럼 미리 정한 형식과 구조 | 정해진 규칙 없이 저장됨 |
| 의미 파악 | 쉽다 | 값만 보고 의미나 특성을 알기 어렵다 |
| 예 | 관계형 데이터베이스 | 텍스트, 영상, 음성 |

### 모델은 함수다

- 모델은 데이터의 패턴을 수식화한 **함수**다. 함수는 입력과 출력의 관계다
- 처음에는 정확한 패턴을 모르니 "이 데이터는 이런 패턴일 것"이라는 **가설 함수**를 정하고, 데이터로 학습시켜 실제 패턴에 **근사**한 함수를 만든다

머신러닝 시리즈에서 본 것과 같은 정의다. 딥러닝에서는 이 가설 함수가 **신경망**이 된다.

## 딥러닝의 특징: 특성 추출을 누가 하는가

머신러닝과 딥러닝 모두 데이터를 학습해 모델을 만든다. 차이는 **특성 추출(feature extraction)** 을 누가 하느냐다.

- 원본 데이터(raw data)에는 패턴 인식에 방해가 되는 **노이즈**가 섞여 있다
- 그래서 노이즈를 걷어 내고 유의미한 특성을 뽑아야 한다. 이 과정을 **데이터 전처리** 또는 **특성 추출**이라고 한다

- **딥러닝**: 모델이 학습하면서 **특성 추출과 분류를 함께** 한다

## 딥러닝 프로세스

**학습 단계**: 학습 데이터를 신경망에 넣어 예측하고, 정답과 비교해 오차를 구한 뒤, 오차가 줄어들도록 파라미터를 업데이트한다. 이를 반복한다.

![학습 단계: 입력 → 신경망 예측 → 오차 계산 → 파라미터 업데이트](/images/dl/fig-dl-train.png)

**평가 단계**: 학습이 끝난 신경망에 테스트 데이터를 넣어 예측하고 평가지표로 성능을 확인한다. 파라미터는 더 이상 바꾸지 않는다.

![평가 단계: 테스트 입력 → 학습된 신경망 → 평가지표](/images/dl/fig-dl-test.png)

학습 단계의 "오차가 줄어들도록 파라미터를 업데이트"가 머신러닝 시리즈의 경사하강법이다. 딥러닝은 파라미터가 수백만~수십억 개라 이 미분을 사람이 직접 할 수 없고, 프레임워크가 자동으로 해 준다. 그 프레임워크가 PyTorch다.

## PyTorch

- Meta(구 Facebook)가 torch와 caffe2를 기반으로 개발한 파이썬 오픈소스 딥러닝 라이브러리
- 구글이 만든 TensorFlow와 함께 딥러닝 프레임워크의 양대 산맥이다

Hugging Face에 올라온 모델을 프레임워크별로 세어 보면 PyTorch가 압도적으로 많다.

![Hugging Face 모델 수: PyTorch only가 TensorFlow only보다 훨씬 많다](/images/dl/fig-pytorch-hf.png)

> **보충** 연구 논문과 Hugging Face 생태계가 PyTorch 중심으로 옮겨 가면서, 새로 나오는 모델 대부분이 PyTorch 코드로 먼저 공개된다. 이 시리즈와 이후 NLP·Hugging Face 시리즈도 PyTorch를 쓴다.

### 설치

1. [pytorch.org](https://pytorch.org/)에 접속한다
2. OS, 패키지 관리자, CUDA 버전 등 자신의 환경을 고르면 설치 명령어가 만들어진다. 그 명령어로 설치한다

```bash
# 예: CPU 전용 (Linux/Windows)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

# 예: macOS (Apple Silicon도 기본 설치로 MPS 사용 가능)
pip install torch torchvision
```

> **보충** NVIDIA GPU를 쓰려면 설치 페이지에서 자신의 CUDA 버전에 맞는 명령어를 골라야 한다. 명령어를 잘못 고르면 GPU가 있어도 CPU 버전이 깔려 `torch.cuda.is_available()`이 `False`로 나온다.

설치가 됐는지, 어떤 장치를 쓸 수 있는지 확인한다.

```python
import torch
print(torch.__version__)
print("CUDA(NVIDIA GPU) 사용 가능:", torch.cuda.is_available())
print("MPS(Apple Silicon) 사용 가능:", torch.backends.mps.is_available())
```

```text
2.5.1
CUDA(NVIDIA GPU) 사용 가능: False
MPS(Apple Silicon) 사용 가능: False
```

이 글을 실행한 환경은 GPU가 없어서 둘 다 `False`다. 학습할 장치는 보통 이렇게 고른다.

```python
device = 'cuda' if torch.cuda.is_available() else 'mps' if torch.backends.mps.is_available() else 'cpu'
device
```

```text
'cpu'
```

| 장치 문자열 | 하드웨어 |
|---|---|
| `"cpu"` | CPU |
| `"cuda"` | NVIDIA GPU |
| `"mps"` | Apple Silicon(M1 이후) GPU. PyTorch 1.12부터 지원 |

## 정리

- 딥러닝은 **인공신경망** 기반의 머신러닝이다
- 머신러닝은 특성 추출을 **사람**이, 딥러닝은 **모델**이 학습하면서 함께 한다. 그래서 딥러닝은 이미지·음성·텍스트 같은 **비정형 데이터**에 강하고, 데이터가 많이 필요하다
- 정형 데이터에서는 머신러닝이 여전히 효율적일 때가 많다
- 학습 단계는 예측 → 오차 계산 → 파라미터 업데이트의 반복이고, 이 미분을 PyTorch가 자동으로 해 준다
- PyTorch는 설치 페이지에서 환경에 맞는 명령어로 설치하고, `cuda` / `mps` / `cpu` 중 쓸 수 있는 장치를 골라 쓴다
